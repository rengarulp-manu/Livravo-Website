Livravo Website
===============

Start:
1. ZIP entpacken
2. index.html im Browser öffnen

Dateien:
- index.html  -> Inhalt der Homepage
- style.css   -> Design
- script.js   -> Menü und Scroll-Animationen
- assets/logo.svg -> Livravo Logo

Download-Button ändern:
In index.html nach "Download bald verfügbar" suchen und href="#" durch deinen späteren Download-Link ersetzen.

Beispiel:
<a href="downloads/LivravoSetup.exe" class="primary-button">Download</a>
